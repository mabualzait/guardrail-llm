## 🚨 Reporting a Vulnerability

If you discover a security issue or vulnerability (such as a Regular Expression Denial of Service vulnerability or a PII leakage vector), please **do not open a public GitHub issue**.

Instead, please send an advisory report to:
- **Email:** `m.abualzait@gmail.com`
- **Subject:** `[SECURITY] guardrail-llm Vulnerability Report`

Please include:
1. Description of the vulnerability.
2. Steps to reproduce or proof-of-concept payload.
3. Potential impact.

We will acknowledge receipt within 48 hours and work with you on a responsible disclosure timeline.
